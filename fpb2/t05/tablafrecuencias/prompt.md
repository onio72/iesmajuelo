# Prompt de reconstrucción — Tabla de frecuencias paso a paso

Crea una aplicación didáctica en español para Formación Profesional Básica (ámbito científico-matemático). Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Genera situaciones cuantitativas o cualitativas con 10–15 datos aleatorios (según código), valores pequeños y categorías del banco. Secuencia guiada reversible: datos brutos, ordenación, valores distintos, frecuencia absoluta n_i, relativa f_i=n_i/N, porcentaje 100f_i y acumuladas cuando proceda. Resalta datos y celdas, explica cada operación, navegación anterior/siguiente, progreso y nuevo problema. MathJax opcional. Verifica suma n_i=N y suma f_i≈1; acumuladas solo para categorías ordenables.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, etiquetas claras y botón Info en flujo normal. Conserva los criterios de evaluación y verifica los casos indicados. Si se usa SCORM, conserva la integración de calificaciones y estado.
