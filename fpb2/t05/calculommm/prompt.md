# Prompt de reconstrucción — Media, mediana y moda

Crea una aplicación didáctica en español para Formación Profesional Básica (ámbito científico-matemático). Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Genera temas cotidianos con 6–10 datos enteros y moda única asegurada mediante frecuencia 3 o 4 y otras frecuencias menores. Datos desordenados y botón ordenar, media aritmética Σx/N, mediana central o promedio central si N par, moda única; tres campos numéricos, tolerancias y redondeo, feedback, puntos por acierto, meta 10, siguiente, reinicio y SCORM. Verifica mediana par/impar y evita empates de moda.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, etiquetas claras y botón Info en flujo normal. Conserva los criterios de evaluación y verifica los casos indicados. Si se usa SCORM, conserva la integración de calificaciones y estado.
