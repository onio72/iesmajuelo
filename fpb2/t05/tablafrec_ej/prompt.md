# Prompt de reconstrucción — Ejercicio de tabla de frecuencias

Crea una aplicación didáctica en español para Formación Profesional Básica (ámbito científico-matemático). Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Tres tablas de datos aleatorios cuantitativos/cualitativos, N entre 10 y 14, ordenación opcional, filas de valores distintos, n_i, f_i=n_i/N y porcentaje. Validación de celdas y totales N,1,100%, tolerancia relativa aproximadamente 0,005 y penalización 0,1 por error, bloqueo/reintento según estado, siguiente tabla tras completarla. Nota, reinicio y SCORM. Acepta formato decimal apropiado, comprueba sumas y redondeos.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, etiquetas claras y botón Info en flujo normal. Conserva los criterios de evaluación y verifica los casos indicados. Si se usa SCORM, conserva la integración de calificaciones y estado.
