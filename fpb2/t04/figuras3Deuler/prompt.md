# Prompt de reconstrucción — Teorema de Euler

Crea una aplicación didáctica en español para Formación Profesional Básica (ámbito científico-matemático). Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Visor Three.js r128 de poliedros convexos, bolsa aleatoria, rotación por arrastre, modos de selección mediante raycasting: vértices, caras completas (no triángulos de la malla) y aristas reales. Clic marca, doble clic desmarca, contadores visuales, campos V,C,A y suma V+C. Evalúa tres respuestas, +10/24 por acierto y −0,2 por error, objetivo 10 con al menos ocho poliedros perfectos, nuevo ejemplo y reinicio. SCORM. Verifica V−A+C=2 para poliedros convexos; no aplicarlo a esfera ni contar diagonales de triangulación.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, etiquetas claras y botón Info en flujo normal. Conserva los criterios de evaluación y verifica los casos indicados. Si se usa SCORM, conserva la integración de calificaciones y estado.
