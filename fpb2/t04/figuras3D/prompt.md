# Prompt de reconstrucción — Reconocer cuerpos geométricos

Crea una aplicación didáctica en español para Formación Profesional Básica (ámbito científico-matemático). Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Visor Three.js r128 de cuerpos geométricos, poliedros y cuerpos redondos. Genera geometrías del banco, orientación inicial aleatoria, arrastre ratón/táctil y zoom, selector alfabético de nombres. Bolsa aleatoria sin repetición hasta agotarla, comprobación y siguiente, +1 por acierto, objetivo 10, reinicio y comunicación de nota SCORM. Distingue prismas, pirámides y cuerpos redondos por sus características; no confundir orientación con tipo.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, etiquetas claras y botón Info en flujo normal. Conserva los criterios de evaluación y verifica los casos indicados. Si se usa SCORM, conserva la integración de calificaciones y estado.
