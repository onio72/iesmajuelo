# Prompt de reconstrucción — Generador de problemas de momento lineal

Crea una aplicación didáctica en español para Física y Química de 1.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Generador con semilla reproducible ID entero (aleatorio 10000–999999), objeto contextual y masa acorde a objeto, rapidez 10–120 km/h, ángulo 0–359°. v_ms=v_kmh/3,6; vx=v cosθ, vy=v senθ, px=mvx, py=mvy, |p|=√(px²+py²). Enunciado, datos, solución desarrollada con MathJax y exportación .tex, modo profesor con acceso configurado y solución oculta por defecto. No copiar claves, hashes ni credenciales; control cliente no es seguridad real. Conserva reproducibilidad de semilla.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva la finalidad didáctica y verifica el modelo.
