# Prompt de reconstrucción — Calculadora de tiro parabólico

Crea una aplicación didáctica en español para Física y Química de 1.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Modelo sin resistencia del aire: vx=v₀cosθ, vy=v₀senθ−gt, x=v₀cosθ·t, y=h₀+v₀senθ·t−½gt². Entradas m≥0,1 kg inicial 1, g≥0,01 inicial 9,81, h₀≥0 inicial 1,5, v₀≥0 inicial 20, θ 0,1–89,9° inicial 45. T=(v₀y+√(v₀y²+2gh₀))/g, alcance vxT, hmax=h₀+v₀y²/(2g), velocidad de impacto y energías según salidas. Canvas con trayectoria, escalas y animación Play/Pausa/Reinicio, resultados y fórmulas KaTeX/MathJax. Verifica independencia de trayectoria respecto a masa.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva la finalidad didáctica y verifica el modelo físico o químico.
