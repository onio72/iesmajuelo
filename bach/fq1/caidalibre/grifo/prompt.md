# Prompt de reconstrucción — Grifo que gotea

Crea una aplicación didáctica en español para Física y Química de 1.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Canvas de grifo con gotas emitidas regularmente, caída desde reposo y sin aire, y=½gt², v=gt hacia abajo. Intervalo 100–2000 ms paso 100 inicial 1000, selector gravedad 1–4, mostrar tiempo de caída y gráfico Chart.js, iniciar/pausa/reinicio/congelar. Cinco preguntas sobre MRUA, efecto de g en tiempo, número de gotas, periodicidad y separación creciente en caída; baraja opciones y corrige. Verifica t_caída=√(2h/g).

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva la finalidad didáctica y verifica el modelo físico o químico.
