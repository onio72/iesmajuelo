# Prompt de reconstrucción — Generador de problemas de tiro parabólico

Crea una aplicación didáctica en español para Física y Química de 1.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Generador determinista de problemas de tiro parabólico a partir de ID de cuatro cifras, carga y nuevo ID, enunciado contextual y simulación Canvas. Modelo x=v₀cosθ·t, y=y₀+v₀senθ·t−½gt² con g=9,8, raíz positiva de impacto, alcance, altura máxima, componentes y módulo de velocidad. Solución matemática paso a paso oculta hasta código facilitado por profesor; panel docente para generar código a partir de ID, copiar y cerrar. Recrea mecanismo de autorización con credenciales configurables, sin copiar contraseñas, claves ni hashes existentes; un control de acceso exclusivamente cliente no constituye seguridad real. MathJax, Tailwind, SweetAlert2 opcionales. Mismo ID reproduce los mismos datos.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva la finalidad didáctica y verifica el modelo físico o químico.
