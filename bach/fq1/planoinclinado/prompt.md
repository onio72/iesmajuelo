# Prompt de reconstrucción — Plano inclinado

Crea una aplicación didáctica en español para Física y Química de 1.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

p5.js 1.9.0, canvas 600×550, triángulo rectángulo de base fija AB, altura AB·tanθ y traslación para mantener márgenes. Deslizadores ángulo 0–60° paso 5 y masa 1–10 kg paso 1. Bloque cuadrado apoyado en mitad de hipotenusa, lado interpolado en función de √m entre 0,1AB y 0,2AB; normal exterior al plano. Etiquetas de masa/ángulo y arco. Solo esquema geométrico, sin cálculo ni animación dinámica. Verifica apoyo correcto al variar θ.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva la finalidad didáctica y verifica el modelo físico o químico.
