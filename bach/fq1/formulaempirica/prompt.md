# Prompt de reconstrucción — Fórmula empírica

Crea una aplicación didáctica en español para Física y Química de 1.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Banco de compuestos con símbolos, porcentajes y masas molares; selecciona al azar. Para 100 g, n_i=%_i/M_i, razón n_i/min(n); editor de fracciones para moles y proporciones, campos de subíndices, corrección de moles y razones a dos decimales, fórmula y porcentaje de acierto, solución desarrollada y otro ejemplo. La versión actual redondea directamente las razones; al reconstruir, comprueba el banco y usa multiplicador entero común cuando haya razones fraccionarias. Omite subíndice 1 en fórmula canónica y acepta 1 explícito como equivalente.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva la finalidad didáctica y verifica el modelo físico o químico.
