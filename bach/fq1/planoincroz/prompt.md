# Prompt de reconstrucción — Plano inclinado con rozamiento

Crea una aplicación didáctica en español para Física y Química de 1.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Simulación de bloque sobre plano, eje positivo descenso, m 0,5–10 kg paso 0,1 inicial 3; θ 0–45° paso 0,5 inicial 20; v₀ −5…5 paso 0,5 inicial 0; materiales y μs/μk 0–1 paso 0,01 inicial 0,4/0,3. N=mgcosθ, componente mgsenθ; reposo si |mgsenθ|≤μsN, en deslizamiento f_k opuesta a v, a=(mgsenθ−sign(v)μkN)/m. Gestiona cruce v=0 y transición a reposo o descenso. Dibuja fuerzas, componentes opcionales, bloque escalado con masa, posición y valores; Play y reinicio. Verifica θ=0 y umbral tanθ=μs.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva la finalidad didáctica y verifica el modelo físico o químico.
