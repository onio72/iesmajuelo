# Prompt de reconstrucción — Choque perfectamente inelástico

Crea una aplicación didáctica en español para Física y Química de 1.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Canvas de dos bolas en una dimensión, m₁,m₂ 1–10 kg inicial 5, v₁ 1–10 inicial 10 y v₂=0. Choque perfectamente inelástico, ambos quedan unidos con v_f=(m₁v₁+m₂v₂)/(m₁+m₂). Tabla p=mv y Ec=½mv² de cada cuerpo y total antes/después. Animar, pausa, reinicio y ralentizar. Diez preguntas numéricas y sí/no con corrección individual y contador. HTML y simulador.js. Verifica conservación de p total y disminución de Ec total (energía transformada, no destruida).

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva la finalidad didáctica y verifica el modelo.
