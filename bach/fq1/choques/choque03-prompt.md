# Prompt de reconstrucción — Choque con coeficiente de restitución

Crea una aplicación didáctica en español para Física y Química de 1.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Dos bolas de igual masa 1–10 kg, tres escenarios (una quieta o ambas acercándose), rapidez sorteada 1–20, e=0,2/0,4/0,6/0,8. Datos de solo lectura. v₁=[(m₁−em₂)u₁+(1+e)m₂u₂]/(m₁+m₂), v₂=[(m₂−em₁)u₂+(1+e)m₁u₁]/(m₁+m₂); e=(v₂−v₁)/(u₁−u₂). Canvas, animar/pausa/reinicio/ralentizar, tablas de p y Ec con 12 campos, cinco cuestiones, enviar y otro ejemplo. Verifica p total constante y Ec menor si e<1 y velocidad relativa inicial no nula.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva la finalidad didáctica y verifica el modelo.
