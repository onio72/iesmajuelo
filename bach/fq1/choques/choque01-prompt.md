# Prompt de reconstrucción — Choque elástico

Crea una aplicación didáctica en español para Física y Química de 1.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Choque frontal elástico e=1, dos bolas de igual masa sorteada 1–10 kg, azul hacia derecha con rapidez 1–20 y roja inicialmente quieta o hacia izquierda. Controles de datos deshabilitados (solo lectura), Canvas, animar/pausa/reinicio/ralentizar. Para masas iguales intercambian velocidades; forma general v₁=[(m₁−em₂)u₁+(1+e)m₂u₂]/(m₁+m₂), v₂=[(m₂−em₁)u₂+(1+e)m₁u₁]/(m₁+m₂). Doce campos de p y Ec, cinco preguntas sobre conservación individual/total y tipo de choque, validación y otro caso. Verifica p total y Ec total.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva la finalidad didáctica y verifica el modelo.
