# Prompt de reconstrucción — Cuerpos enlazados

Crea una aplicación didáctica en español para Física y Química de 1.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Bloque m₁ sobre mesa y m₂ colgante, cuerda y polea ideales, g=9,8. Masas 1–10 kg paso 0,1 inicial 5; μ 0–1 paso 0,01 inicial 0,1. Modelo de umbral m₂g>μm₁g; si desciende, a=(m₂g−μm₁g)/(m₁+m₂), T=m₂(g−a). Si estático, T=m₂g y rozamiento se ajusta hasta límite. Canvas, inicio/detener/reinicio, mostrar fuerzas y aceleración o todas fuerzas, ralentizar y reloj. Cuestionario cuatro preguntas y corrección. Explica aproximación de un único μ y diferencia entre estático/cinético.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva la finalidad didáctica y verifica el modelo físico o químico.
