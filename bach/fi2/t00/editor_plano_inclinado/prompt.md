# Prompt de reconstrucción — Editor de diagramas de fuerzas · Plano inclinado

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Editor SVG de bloque en plano inclinado, inclinación 10–60° inicial 30, tamaño 38–82 inicial 58, escala longitud vectores 50–160% inicial 100. Catálogo de fuerzas, selección para añadir/editar, flechas desde centro con extremos arrastrables, colores/etiquetas, ejes paralelo/normal y ángulo opcionales. Restablecer vectores, quitar todas, exportar SVG renderizado a JPG mediante Canvas con recorte adecuado. No es simulación dinámica ni evaluación. Verifica exportación completa sin recortar flechas.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades SI y botón Info integrado en flujo normal junto al título con instrucciones. Conserva la evaluación y comprueba los casos indicados.
