# Prompt de reconstrucción — Vector unitario en la dirección AB

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Genera dos puntos distintos en cuadrícula, cinco apartados (coordenadas A, B, componentes AB, módulo y unitario). AB=(Bx−Ax,By−Ay), |AB|=√(dx²+dy²), u=AB/|AB|. Tolerancia ±0,01, acepta coma/punto, ayudas, calculadora móvil y PDF de resultados. SCORM 1.2 con puntuación de primer intento, estado y reanudación; permite corregir para avanzar. Verifica módulo del unitario 1 y signos.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades SI y botón Info integrado en flujo normal junto al título con instrucciones. Conserva la evaluación y comprueba los casos indicados.
