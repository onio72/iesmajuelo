# Prompt de reconstrucción — Fuerzas y movimiento

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Itinerario ramificado de decisiones: ninguna/una/varias fuerzas, reposo o movimiento inicial, resultante en mismo sentido/opuesto/oblicuo a velocidad. Visualiza cuerpo, fuerzas individuales o resultante, velocidad y trayectoria mediante animación; a=ΣF/m, v=v0+at, r=r0+v0t+½at² para fuerza constante. Play/Pausa/Reiniciar, panel decisiones y representación. Distingue MRU si resultante nula, aceleración/desaceleración o cambio de dirección. Verifica no confundir fuerza con velocidad.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades SI y botón Info integrado en flujo normal junto al título con instrucciones. Conserva la evaluación y comprueba los casos indicados.
