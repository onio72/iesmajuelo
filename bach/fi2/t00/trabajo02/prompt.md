# Prompt de reconstrucción — Desplazamiento, trabajo y energía cinética

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Genera situaciones aleatorias equilibradas de trabajo positivo, negativo y cero. Representación de A/B y vector F con etiquetas sin solaparse. Calcula Δr=B−A, F por componentes, W=FxΔx+FyΔy, ángulo agudo/recto/obtuso según signo para vectores no nulos, ΔEc=Wneto. Campos y opciones, corrección, nota por primer intento, calculadora local, informe PDF y SCORM 1.2 con persistencia. Verifica fuerza perpendicular da W=0.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades SI y botón Info integrado en flujo normal junto al título con instrucciones. Conserva la evaluación y comprueba los casos indicados.
