# Prompt de reconstrucción — Diagramas de fuerzas · práctica adaptativa

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Actividad adaptativa de diagramas de cuerpo libre, con situaciones variadas y niveles. Selección de fuerzas, confirmación y dibujo de vectores desde el centro; valida tipo, orientación y proporciones (escala gráfica, no magnitud absoluta), ejes paralelo/normal y horizontal/vertical, deshacer, cambiar fuerzas, pistas y calculadora. Flechas grises discontinuas de movimiento/aceleración no son fuerzas. Comparación respuesta/solución, progreso por destrezas, actualización bayesiana de dominio y selección adaptativa de dificultad; informe y simulación Monte Carlo interna no validación real. SCORM 1.2, nota 0–10, reanudación. Interfaz legible para proyección y responsive.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades SI y botón Info integrado en flujo normal junto al título con instrucciones. Conserva la evaluación y comprueba los casos indicados.
