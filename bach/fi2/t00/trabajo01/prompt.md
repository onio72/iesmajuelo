# Prompt de reconstrucción — Trabajo mecánico: medida gráfica de vectores

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Genera A,B y F aleatorios en cuadrícula, desplazamiento B−A. Herramientas regla y transportador ajustable −5°,−1°,+1°,+5°, zoom y centrar A; dibujar desplazamiento, medir módulos y ángulo, calcular W=F·Δr=F Δr cosθ. Cinco apartados por ejercicio, seis ejercicios (30 aciertos del primer intento equivalen a 10), corrección y reintentos sin aumentar nota, avanzar tras 5/5. Calculadora local en grados, informe PDF, SCORM 1.2 con suspensión y nota. Notación vectorial sin CDN. Verifica signos de W.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades SI y botón Info integrado en flujo normal junto al título con instrucciones. Conserva la evaluación y comprueba los casos indicados.
