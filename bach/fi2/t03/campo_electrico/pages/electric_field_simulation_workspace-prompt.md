# Prompt de reconstrucción — Calculadora de campo eléctrico

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Calculadora 2D de campo de dos cargas puntuales con k=8,99·10⁹ N·m²/C². Configura módulos, unidades y polaridad por separado, coordenadas y punto P. Para cada fuente d=P−r_i, u=d/|d|, E_i=kq_i u/|d|²; suma por componentes, módulo y ángulo respecto a +X. Cuadrícula con arrastre, colocación, zoom y reset zoom, limpiar y auto. Panel de cálculos separado y plegable, vectores posición/unitarios, contribuciones y total, notación científica y fórmulas legibles. Impide coincidencia singular. Verifica signos y cancelación para cargas iguales en punto medio; cargas opuestas refuerzan allí.

## Requisitos

Entrega código completo y funcional, diseño adaptable, controles accesibles, unidades SI y botón Info integrado en flujo normal junto al título con instrucciones. Conserva el comportamiento didáctico y los sistemas de evaluación y comprueba los casos indicados.
