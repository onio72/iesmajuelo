# Prompt de reconstrucción — Regla de la mano izquierda

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Visor React y Three.js/WebGL de mano articulada, modelo local con atribución original © 2026 Emma L. D. Lieker si se reutiliza con autorización; alternativa propia. Selectores de ejes x,y,z y sentidos ± para B y v, impide ejes iguales; orienta índice según B, corazón según v y pulgar según v×B para carga positiva. F=q(v×B), signo invertido si q<0. Vectores coloreados y leyenda, Mostrar F, Centrar vista, giro de cámara y mensajes de carga/error WebGL. Modelo 3D, bibliotecas y CSS locales para paquete SCORM 1.2; no modificar atribución ni lógica de visor. Verifica v=+x,B=+y→F positiva +z.

## Requisitos

Entrega código completo y funcional, diseño adaptable, controles accesibles, unidades SI y botón Info integrado en flujo normal junto al título con instrucciones. Conserva el comportamiento didáctico y los sistemas de evaluación y comprueba los casos indicados.
