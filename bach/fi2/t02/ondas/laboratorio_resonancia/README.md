# Laboratorio virtual de resonancia mecánica

Física de 2.º de Bachillerato. Tres osciladores forzados y amortiguados por una base común; medición de amplitudes y exportación CSV. Frecuencias propias didácticas: 2,80; 1,60; 0,90 Hz.

Estilo: `herramientas/estilos/v1/laboratorio.css` (v1.0.0), por su carácter experimental. Colores físicos: naranja (corta), azul (media), verde (larga). Se conserva la integración RK4 y los controles originales.

Comprobación: sintaxis JavaScript validada; revisión visual, móvil y consola en navegador pendientes.
