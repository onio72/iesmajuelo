# Una fase constante en movimiento

Comprende qué significa seguir una fase constante de una onda viajera.



## Experimenta paso a paso

- Elige una fase y pulsa Reproducir. Observa cómo se desplaza el punto que conserva esa fase.
- Cambia el sentido de propagación y usa los pasos de ±0,1 s para comparar posiciones.
- Activa las fases equivalentes y usa Mostrar siguiente paso para seguir la deducción.


## Qué debes comprender

La fase constante cumple ωt ± kx + φ₀ = constante. Su velocidad tiene módulo ω/k = λ/T.
