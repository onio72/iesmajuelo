# Resonancia de una cuerda bajo tensión

Estudia la resonancia de una cuerda bajo tensión.



## Experimenta paso a paso

- Elige Variar longitud, Variar tensión o Pesar la cuerda y observa las magnitudes disponibles.
- Modifica una variable cada vez y busca las condiciones en las que aparecen modos de vibración definidos.
- Usa Registrar para conservar las medidas y compáralas antes de borrar los datos.


## Qué debes comprender

La velocidad en la cuerda es √(F/μ); para extremos fijos, las frecuencias normales son n v/(2L).
