# Prompt de reconstrucción — Modos normales de vibración

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente; no es el original.

## Modelo e interfaz

Cuerda de 10 m, v=2 m/s, amplitud arbitraria 1, extremo derecho fijo y vibrador izquierdo. Representa onda incidente y reflejada invertida y su superposición; usa modelo didáctico de resonancia de cuarto de onda (extremo emisor tipo antinodo y fijo tipo nodo). Frecuencia fundamental v/(4L)=0,05 Hz, modos impares n=1,3,5,7,9,11,13,15. Deslizador 0,01–0,825 Hz paso 0,001 inicial 0,05, marcas de resonancia y detección con tolerancia 0,02 en f/f₀. Canvas, colores de nodos y vientres, indicador de estado y λ=v/f. Distingue modelo idealizado de excitación de una cuerda con desplazamiento impuesto. Comprueba que el extremo derecho permanece fijo y los modos impares satisfacen L=nλ/4.

## Requisitos técnicos

Entrega HTML, CSS y JavaScript completos para GitHub Pages; interfaz adaptable, controles accesibles, unidades y etiquetas legibles, botón Info integrado en flujo normal, modal con instrucciones y cierre mediante Escape. Conserva el modelo físico y comprueba los casos descritos.
