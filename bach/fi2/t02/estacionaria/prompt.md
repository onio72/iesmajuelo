# Prompt de reconstrucción — Laboratorio de ondas estacionarias

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente; no es el original.

## Modelo e interfaz

Simulación interactiva de modos estacionarios de cuerda fija en ambos extremos: λ=2L/n, T=λ/v, k=2π/λ, ω=2π/T. Componentes A sen(kx−ωt) y A sen(kx+ωt), resultante 2A sen(kx) cos(ωt). Sortea modo y amplitud A de 0,5,1,1,5 m; cuadrícula de 0,25 m. Dibuja resultante y componentes en lienzos sincronizados; pausa, pasos, velocidad 0,1–1,5× y nuevo ejemplo. Actividad por fases de identificación de nodos y vientres, selección sobre gráfica con tolerancia y marcadores. Cuestionario final de cinco cálculos (n,λ,T,A,2A) y cinco conceptos sí/no sobre frecuencia y amplitudes, orden aleatorio y corrección. Aclara que en nodos no hay oscilación aunque la solución tenga frecuencia común. Verifica n+1 nodos, n vientres y separación λ/2.

## Requisitos técnicos

Entrega HTML, CSS y JavaScript completos para GitHub Pages; interfaz adaptable, controles accesibles, unidades y etiquetas legibles, botón Info integrado en flujo normal, modal con instrucciones y cierre mediante Escape. Conserva el modelo físico y comprueba los casos descritos.
