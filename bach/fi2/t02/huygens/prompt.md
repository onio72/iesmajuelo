# Prompt de reconstrucción — Principio de Huygens

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente; no es el original.

## Modelo e interfaz

Simulación geométrica de frentes planos en frontera de dos medios homogéneos e isótropos. v₂/v₁=n₁/n₂, r=asin(n₁ sen i/n₂) si argumento ≤1; si supera 1, no hay onda refractada propagante. Reflexión con i=r_ref. Construcción por ondas secundarias que crecen desde los puntos alcanzados y envolventes; múltiples frentes incidente, reflejado y refractado, rayos perpendiculares, etiquetas separadas y sin fondo. Etapas anterior/siguiente, reproducir, reiniciar y progreso 0–3 paso 0,002; n₁,n₂ 1–2,5 paso 0,05 inicial 1 y 1,5; incidencia 0–80° inicial 40°; ritmo 0,1–3×; casillas ondas secundarias, reflexión, rayos y normal. Canvas adaptable. Verifica Snell, igualdad de ángulos de reflexión y ausencia de refracción propagante en reflexión total.

## Requisitos técnicos

Entrega HTML, CSS y JavaScript completos para GitHub Pages; interfaz adaptable, controles accesibles, unidades y etiquetas legibles, botón Info integrado en flujo normal, modal con instrucciones y cierre mediante Escape. Conserva el modelo físico y comprueba los casos descritos.
