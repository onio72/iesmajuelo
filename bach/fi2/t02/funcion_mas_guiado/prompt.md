# Prompt de reconstrucción — ¿Qué función uso para describir un MAS?

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente, no es el original.

## Modelo, interfaz y comportamiento

Dos itinerarios alternativos guiados: gráficas con curvas desplazables (h −2π…2π), circunferencia goniométrica con proyecciones de radio y ángulo agudo 15–75° inicial 37°. Cuatro casos: sen(x+π/2)=cos x; sen(x−3π/2)=cos x; cos(x−π/2)=sen x; cos(x+3π/2)=sen x. Identificación, manipulación, comprobación y cuaderno de descubrimientos; bloquea pasos hasta completar. Reiniciar y elegir otro método. SVG/canvas adaptable, sin recopilación de respuestas. Comprueba cada identidad para ángulos distintos.

## Requisitos técnicos

Entrega HTML, CSS y JavaScript completos, listos para GitHub Pages, sin servidor. Interfaz adaptable, controles accesibles, unidades y etiquetas legibles; coloca Info en flujo normal junto al título y muestra las instrucciones de uso en un modal. Conserva el modelo físico y comprueba los casos descritos.
