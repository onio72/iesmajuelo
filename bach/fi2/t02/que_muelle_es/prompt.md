# Prompt de reconstrucción — ¿Qué muelle es?

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente, no es el original.

## Modelo, interfaz y comportamiento

Dos osciladores verticales y dos representaciones de posición/velocidad/aceleración en ecuación o gráfica, casos aleatorios, escala gráfica común, eje temporal por cero y unidades SI; posición positiva arriba, animación ampliada. Asociación bidireccional por colores, segunda automática; comprobar, otro ejercicio, reiniciar animación y puntuación. +1 acierto, −1 error, mínimo 0; verde por encima de 5, termina al llegar a 10. Mantén compatibilidad LMS SCORM y progreso temporal local fuera de Moodle. Verifica que no se puede puntuar dos veces el mismo ejercicio.

## Requisitos técnicos

Entrega código completo, listo para publicar en GitHub Pages, sin servidor. Interfaz adaptable, controles accesibles, unidades y etiquetas legibles; coloca Info en flujo normal junto al título y muestra las instrucciones en un modal. Conserva el modelo físico y comprueba los casos descritos.
