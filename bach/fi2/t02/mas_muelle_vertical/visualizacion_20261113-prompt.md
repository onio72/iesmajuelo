# Prompt de reconstrucción — Gráficas del MAS

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente, no es el original.

## Modelo, interfaz y comportamiento

Muelle vertical ideal con m=1 kg, k=4 N/m, ω=2 rad/s, T=π s. y=A cos θ, v=−Aω sen θ, a=−ω²A cos θ. Eje positivo arriba, origen equilibrio estático. Vectores v/a y valores activables, referencia, tres gráficas temporales seleccionables y superposición normalizada −1…1. Play/Pausa, reinicio/inicio, ±0,10 s, deslizador 0–18,85 s, cámara lenta ×0,20. Selector de cuatro puntos clave, aproximación desde 0,75 s antes, repetir y detener en instante exacto. Mantén diseño estable sin solapar controles. Comprueba a=0 en equilibrio y v=0 en extremos.

## Requisitos técnicos

Entrega HTML, CSS y JavaScript completos, listos para GitHub Pages, sin servidor. Interfaz adaptable, controles accesibles, unidades y etiquetas legibles; coloca Info en flujo normal junto al título y muestra las instrucciones de uso en un modal. Conserva el modelo físico y comprueba los casos descritos.
