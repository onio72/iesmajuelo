# Prompt de reconstrucción — MAS · Cálculo de la ecuación

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente, no es el original.

## Modelo, interfaz y comportamiento

Ejercicios aleatorios con condiciones iniciales compatibles; seis etapas desbloqueadas: representar posición y sentido de v (arrastre/teclado y flecha invertible, v=0 en extremos), elegir seno/coseno, A y ω (π/2,π,2π,4π), construir y,v,a con signos y funciones, fase entre ángulos notables con pista, comparar y reproducir ambas soluciones. Valida posición y signo de velocidad, parámetros, derivadas y fase con retroalimentación por etapa. Acepta coma decimal. Otro problema reinicia. Las soluciones equivalentes deben coincidir para todo t.

## Requisitos técnicos

Entrega HTML, CSS y JavaScript completos, listos para GitHub Pages, sin servidor. Interfaz adaptable, controles accesibles, unidades y etiquetas legibles; coloca Info en flujo normal junto al título y muestra las instrucciones de uso en un modal. Conserva el modelo físico y comprueba los casos descritos.
