# Prompt de reconstrucción — Dinámica del movimiento armónico simple

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente, no es el original.

## Modelo, interfaz y comportamiento

Muelle vertical con longitud natural L₀ y masa 0,25–0,80 kg paso 0,05 inicial 0,45. Arrastre para colgar, asentamiento amortiguado inicial, medidas L_eq y L₀, comprobaciones sucesivas ΔL, mg, k=mg/ΔL (2–3 cifras significativas). Después movimiento ideal sin amortiguamiento, arrastre y soltado, pausa/equilibrio, vectores peso, fuerza elástica y resultante con valores activables y signos según eje positivo abajo. Tope de compresión para evitar longitud negativa. Cinco cuestiones conceptuales con corrección. Verifica ΣF=0 en equilibrio y fuerza hacia él a ambos lados.

## Requisitos técnicos

Entrega código completo, listo para publicar en GitHub Pages, sin servidor. Interfaz adaptable, controles accesibles, unidades y etiquetas legibles; coloca Info en flujo normal junto al título y muestra las instrucciones en un modal. Conserva el modelo físico y comprueba los casos descritos.
