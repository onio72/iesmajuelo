# Prompt de reconstrucción — Descubriendo el movimiento armónico simple

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente, no es el original.

## Modelo, interfaz y comportamiento

Muelle vertical ideal sin rozamiento, eje positivo hacia arriba, y=±A cos(ωt) al soltar desde reposo; v=dy/dt, a=−ω²y. Conserva el itinerario guiado con desbloqueo de actividades, arrastre de masa y soltado, reproducción y pasos ±0,10 s, tablas de capturas de y,v,a con gráficas experimentales, limpieza, accesos +A, equilibrio descendente, −A y equilibrio ascendente. Incluye comparación de oscilaciones y períodos. No muestres resultados antes de la exploración. Verifica v=0 en extremos y a=0 en equilibrio.

## Requisitos técnicos

Entrega HTML, CSS y JavaScript completos, listos para GitHub Pages, sin servidor. Interfaz adaptable, controles accesibles, unidades y etiquetas legibles; coloca Info en flujo normal junto al título y muestra las instrucciones de uso en un modal. Conserva el modelo físico y comprueba los casos descritos.
