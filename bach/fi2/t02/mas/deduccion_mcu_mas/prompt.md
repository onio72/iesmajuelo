# Prompt de reconstrucción — Deducción de las ecuaciones del movimiento armónico simple

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente, no es el original.

## Modelo, interfaz y comportamiento

Presentación de 13 pasos: giro/proyección, fase, descomposición radio vector, componente Y, sustitución, A=R, derivación, regla cadena, velocidad, segunda derivación, regla cadena, aceleración, síntesis. SVG de círculo y muelle sincronizados, vectores según escena, panel matemático con fracciones y unidades. R 0,5–1,5 m inicial 1,2; ω −π…π inicial π/2, φ₀ −π…π inicial π/6, atracción a fracciones de π; control temporal, anterior/siguiente/inicio, reproducir y t=0, pantalla completa. v_max=A|ω|, a=−ω²y. Comprueba proyección y signo para giro horario.

## Requisitos técnicos

Entrega HTML, CSS y JavaScript completos, listos para GitHub Pages, sin servidor. Interfaz adaptable, controles accesibles, unidades y etiquetas legibles; coloca Info en flujo normal junto al título y muestra las instrucciones de uso en un modal. Conserva el modelo físico y comprueba los casos descritos.
