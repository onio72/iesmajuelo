# Prompt de reconstrucción — El MAS como proyección del MCU · 3D

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente, no es el original.

## Modelo, interfaz y comportamiento

Implementa escena 3D con Three.js 0.160.0 (import map y OrbitControls), disco motorizado, vástago y proyectores perpendiculares, pantallas, haces y sombras. x=A cos(ωt+φ₀), y=A sen(ωt+φ₀). Radio 0,3–1,2 m paso 0,05 inicial 0,8; ω 0,5–6 rad/s paso 0,1 inicial 1,5; φ₀ 0–360° paso 5; ritmo 0,1–2×. Vistas predefinidas, cámara orbitable, pausa, ±0,05 s y reinicio. Gráficas de proyecciones, focos independientes y oscuridad opcional. Comprueba coincidencia de sombras y coordenadas en cada instante.

## Requisitos técnicos

Entrega HTML, CSS y JavaScript completos, listos para GitHub Pages, sin servidor. Interfaz adaptable, controles accesibles, unidades y etiquetas legibles; coloca Info en flujo normal junto al título y muestra las instrucciones de uso en un modal. Conserva el modelo físico y comprueba los casos descritos.
