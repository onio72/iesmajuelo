# Comparador MAS — Tema 02 · Física 2.º Bachillerato

Versión de práctica con dos osciladores verticales, casos aleatorios de amplitud, período y frecuencia, fase inicial variable y regla de referencia horizontal arrastrable desde el equilibrio.

## SCORM 1.2
El paquete ZIP tiene imsmanifest.xml en la raíz, y el HTML evaluable es autónomo. +1 acierto, −1 fallo, puntuación de 0 a 10, aprobado desde 5, cierra al llegar a 10. Guarda progreso en cmi.suspend_data y nota en cmi.core.score.raw tras cada respuesta, al suspender y al salir. La revisión y nuevos intentos los gestiona Moodle.

## Estilo
Referencia prevista: cuestiones.css v1 para actividades de selección. Esta versión conserva CSS local integrado para que la vista previa y el ZIP sean autónomos; la migración completa al diseño común queda pendiente. Azul identifica A, naranja B, gris el equilibrio y magenta la guía de referencia.

## Validación
Sintaxis JavaScript y estructura del manifiesto verificadas; falta validar el seguimiento SCORM en un entorno real de Moodle Centros.

La aplicación presenta exclusivamente las preguntas comparativas. Se ha eliminado la pestaña de exploración de variables.
