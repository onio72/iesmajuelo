# Prompt de reconstrucción — Seno y coseno: la misma curva, diferente fase

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente, no es el original.

## Modelo, interfaz y comportamiento

Dos curvas sinusoidales sobre ejes compartidos con marcas en múltiplos de π. Una permanece fija; la otra se desplaza h entre −2π y 2π, paso 0,005π, con ecuación dinámica sen(x−h) o cos(x−h). Botones mover seno/coseno, reiniciar y presets ±π/2,±3π/2,0. Detecta coincidencia módulo 2π con tolerancia angular 0,012 rad; no confundir desplazamiento con signo del argumento. Verifica las cuatro equivalencias.

## Requisitos técnicos

Entrega HTML, CSS y JavaScript completos, listos para GitHub Pages, sin servidor. Interfaz adaptable, controles accesibles, unidades y etiquetas legibles; coloca Info en flujo normal junto al título y muestra las instrucciones de uso en un modal. Conserva el modelo físico y comprueba los casos descritos.
