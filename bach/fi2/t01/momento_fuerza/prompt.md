# Prompt de reconstrucción — Momento de una fuerza en el espacio

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Barra de longitud constante orientada según eje, r desde O de longitud 0, mitad o totalidad; F aplicada en extremo de r, colineal o perpendicular. M=r×F, cálculo por componentes. SVG 3D con cámara giratoria, ejes y flechas, botones girar/restablecer; radio existencia/eje/sentido, corrección y nuevo caso. Verifica M=0 si r=0 o F paralela a r; signo mediante mano derecha. Incluye calculadora científica si procede.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
