# Prompt de reconstrucción — ¿Dónde se anula la fuerza gravitatoria?

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

SCORM 1.2 de dos masas positivas en eje, punto nulo x=d√M₁/(√M₁+√M₂). Diez retos, puntuación por caso 0,25 gráfico, 0,25 región y 0,50 numérico (±0,02 m); marca aproximada evaluada separadamente. Calculadora local, solo Bien/Mal durante evaluación, informe PDF y soluciones finales, conservación de progreso y nota 0–100 mediante API SCORM. Verifica no hay cancelación exterior.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
