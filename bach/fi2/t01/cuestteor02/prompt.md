# Prompt de reconstrucción — Tema 1: Interacción gravitatoria. Control de variables (II)

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Seis temas orbitales y escape: Velocidad de escape √(2GM/R), velocidad circular √(GM/r), período 2π√(r³/GM), Ec=GMm/(2r), Ep=−GMm/r, Em=−GMm/(2r). Usa exponentes 1/2, −1/2, 3/2, −1 y 1. Calcula cociente multiplicando factores elevados a exponentes; aclara órbitas circulares y distingue el cociente de una energía negativa de un aumento algebraico. Genera cambios paramétricos, presenta ecuaciones de estados inicial y final con colores, deduce cociente y simplifica enteros, fracciones y radicales con MathJax. Cuatro opciones únicas, corrección, puntuación, siguiente parámetro y calculadora. Prueba T∝r^{3/2} y v∝r^{−1/2}.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
