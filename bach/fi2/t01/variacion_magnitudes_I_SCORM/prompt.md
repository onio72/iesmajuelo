# Prompt de reconstrucción — Tema 1: Interacción gravitatoria. Control de variables (I)

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Cuatro temas de interacción y campo: F=GMm/r², g=GM/r², Ep=−GMm/r, V=−GM/r. Para Q=C∏x_i^{p_i}, el cociente Q₂/Q₁=∏factor_i^{p_i}; cancela constantes y compara magnitudes negativas mediante su cociente positivo sin confundir aumento algebraico con módulo. Factores 2,3,4,1/2,1/3,1/4 y 1; al menos un cambio, distractores por inversión o factores comunes, fracciones exactas. Diez ejercicios de opción múltiple, cuatro opciones sin duplicados, un punto por acierto sin penalización, aprobado 5/10, bloqueo de corrección repetida, siguiente ejercicio e informe PDF imprimible. Guarda estado, nota 0–10, suspensión y reanudación mediante SCORM 1.2 (LMSInitialize, LMSSetValue, LMSCommit, LMSFinish), respaldo local fuera del LMS. Empaqueta manifiesto y todos los recursos locales.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
