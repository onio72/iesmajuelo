# Prompt de reconstrucción — Momento angular de una partícula en el espacio

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Versión evaluable SCORM 1.2 de ejercicios de momento angular: r y p sobre ejes, casos colineales y perpendiculares, producto vectorial L=r×p, SVG 3D giratorio, radios sí/no/eje/signo, corrección y nuevo caso. Conserva puntuación, estado de finalización y reanudación con LMSInitialize, LMSSetValue, LMSCommit y LMSFinish; recursos locales y manifiesto. Verifica signo, nulidad y que la corrección no duplique calificaciones.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
