# Prompt de reconstrucción — Tema 1: Interacción gravitatoria. Control de variables

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Banco paramétrico de diez expresiones: F=GMm/r², g=GM/r², Ep=−GMm/r, V=−GM/r. Para Q=C∏x_i^{p_i}, el cociente Q₂/Q₁=∏factor_i^{p_i}; cancela constantes y compara magnitudes negativas mediante su cociente positivo sin confundir aumento algebraico con módulo. Velocidad de escape √(2GM/R), velocidad circular √(GM/r), período 2π√(r³/GM), Ec=GMm/(2r), Ep=−GMm/r, Em=−GMm/(2r). Usa exponentes 1/2, −1/2, 3/2, −1 y 1. Calcula cociente multiplicando factores elevados a exponentes; aclara órbitas circulares y distingue el cociente de una energía negativa de un aumento algebraico. Ep aparece en dos contextos (general y orbital). Selección personalizada de temas todas/ninguna, sorteo restringido a activos, factores 2,3,4,1/2,1/3,1/4 y constantes; al menos una variable cambia. Opciones únicas, corrección, puntuación y explicación comparativa con sustitución y cancelación. MathJax para fracciones y radicales, subíndices correctos, siguiente pregunta. Verifica que duplicar distancia divide F y g por cuatro, cuadruplicar radio orbital multiplica T por ocho.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
