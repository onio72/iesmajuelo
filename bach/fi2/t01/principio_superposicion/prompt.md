# Prompt de reconstrucción — Principio de superposición

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Dos masas generadoras 1–100·10¹⁰ kg (50/75 inicial), punto P y masa test 1–20 en escala del modelo, G=6,67430·10⁻¹¹. g_i=GM_i(r_i−P)/|r_i−P|³, F_i=m g_i, V_i=−GM_i/r_i, E_i=m V_i. Sumas vectoriales por componentes y escalares directas. Arrastre con ajuste independiente de coordenada de fuentes cerca de entero (0,2 m), P libre; evita singularidad <0,12 m. Flechas rojo/azul/verde con escala común adaptativa, casillas y componentes, resultados y explicación. Verifica masa testigo solo influye en F y E.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
