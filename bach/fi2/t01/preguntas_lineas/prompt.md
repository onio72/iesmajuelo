# Prompt de reconstrucción — Líneas de campo gravitatorio · Preguntas

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Generador de situaciones 2D con masas puntuales positivas ocultas por discos blancos de tamaño no representativo. Campo por suma de contribuciones radiales, semillas de líneas aproximadamente proporcionales a masa e integración numérica de dirección local; flechas hacia masas. Preguntas conceptuales sobre masas relativas, dirección y distribución del campo, respuestas barajadas. Cambiar imagen, siguiente pregunta, reiniciar puntuación, +0,5 acierto y −0,5 error. Aclara que densidad dibujada es representación aproximada y que todos los cuerpos atraen.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
