# Prompt de reconstrucción — Laboratorio socrático de energía

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Dos pestañas: 15 cuestiones conceptuales con retroalimentación y casos guiados de fuerzas/trabajos. Wtotal=ΔEc, Wc=−ΔEp, Wnc=ΔEm y Wtotal=Wc+Wnc. Incluye ocho situaciones: rozamiento horizontal, caída libre, lanzamiento ascendente, motor horizontal, descenso con rozamiento, rozamiento dominante, órbita circular y fuerzas no conservativas opuestas. En cada caso clasifica fuerzas, identifica signos y magnitudes de trabajos, deduce variaciones y evalúa afirmación inicial; matriz se completa solo con aciertos, pistas, reinicio y otro reto. Distingue fuerza actuante de fuerza que realiza trabajo; no infieras un signo cuando datos son insuficientes.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
