# Prompt de reconstrucción — Vamos a calcular de dos formas distintas la diferencia de energía potencial entre el suelo y un punto situado a 5 metros de altura

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Dos paneles de cálculo para alturas 5 m, 50 km, 500 km, m=1 kg, G=6,67·10⁻¹¹, M=5,972·10²⁴ kg, R=6370000 m, g=9,8 m/s². Aproximación ΔE=mgh con cero en suelo; general E(r)=−GMm/r con cero infinito, ΔE=GMm(1/R−1/(R+h)). Presenta esquemas, sustitución, resultados y error relativo; distingue error geométrico h/R si g₀=GM/R² de error numérico por redondear g. Verifica convergencia cuando h≪R y que ΔE es positiva al ascender.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
