# Prompt de reconstrucción — ¿Qué muelle tiene mayor constante elástica?

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente, no es el original.

## Modelo, interfaz y comportamiento

Cinco muelles con constantes distintas sorteadas y cinco masas 100 g, g=9,8. Arrastre o toque de bloque y destino, respuesta transitoria amortiguada hacia equilibrio ΔL=mg/k. Cinta graduada desplazable con cero en L₀, flechas izquierda/derecha, fichas de k arrastrables, comprobar asociaciones, resultados y explicación, reiniciar colocaciones/nuevo reto. No revele k de cada muelle antes de corregir. Verifica relación inversa y unidades N/m.

## Requisitos técnicos

Entrega código completo, listo para publicar en GitHub Pages, sin servidor. Interfaz adaptable, controles accesibles, unidades y etiquetas legibles; coloca Info en flujo normal junto al título y muestra las instrucciones en un modal. Conserva el modelo físico y comprueba los casos descritos.
