# Prompt de reconstrucción — Tema 1: Interacción gravitatoria. Control de variables (II)

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Seis temas: Velocidad de escape √(2GM/R), velocidad circular √(GM/r), período 2π√(r³/GM), Ec=GMm/(2r), Ep=−GMm/r, Em=−GMm/(2r). Usa exponentes 1/2, −1/2, 3/2, −1 y 1. Calcula cociente multiplicando factores elevados a exponentes; aclara órbitas circulares y distingue el cociente de una energía negativa de un aumento algebraico. Factores 2,3,4,6,9,12,1/2,1/3,1/4 y 1; al menos un cambio. Calculadora local arrastrable con raíz, EXP e inverso. Diez ejercicios de opción múltiple, cuatro opciones sin duplicados, un punto por acierto sin penalización, aprobado 5/10, bloqueo de corrección repetida, siguiente ejercicio e informe PDF imprimible. Guarda estado, nota 0–10, suspensión y reanudación mediante SCORM 1.2 (LMSInitialize, LMSSetValue, LMSCommit, LMSFinish), respaldo local fuera del LMS. Empaqueta manifiesto y todos los recursos locales.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
