# Prompt de reconstrucción — MCU y MAS · Reto de fase inicial

Crea desde cero una aplicación educativa en español para Física de 2.º de Bachillerato. Este prompt reconstruye la versión vigente, no es el original.

## Modelo, interfaz y comportamiento

Reto aleatorio con y=A sen(ωt+φ₀), positivo arriba, fase 0–360° módulo 360. Muelle con referencias ±A,±3A/4,±A/2,±A/4; reproducción, paso atrás/adelante, reinicio, ritmo 0,25–2×. Menús grados y radianes con π, validación de ambas representaciones, pista, solución disponible después de error, otro movimiento. Tras resolver, MCU sincronizado, repetir desde t=0, gráficas y,v,a activables. Valida signos de seno y coseno, extremos y equivalencia de fases.

## Requisitos técnicos

Entrega código completo, listo para publicar en GitHub Pages, sin servidor. Interfaz adaptable, controles accesibles, unidades y etiquetas legibles; coloca Info en flujo normal junto al título y muestra las instrucciones en un modal. Conserva el modelo físico y comprueba los casos descritos.
