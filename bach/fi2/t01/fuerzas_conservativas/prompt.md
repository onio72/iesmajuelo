# Prompt de reconstrucción — Fuerzas conservativas: ¿depende el trabajo del camino?

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Campo conservativo 2D U(x,y)=1,2x²+0,7y²+0,8xy J; F=−∇U=(−2,4x−0,8y,−1,4y−0,8x). Dos curvas entre A y B, integración numérica de F·dr, acumulación y trabajo total; modo C₁ A→B + C₂ B→A (cerrado) y ambos A→B. Canvas con P, flechas fuerza y desplazamiento, campo opcional y valores, deslizador posición 0–1000, reproducir/reiniciar. Verifica W_AB=U(A)−U(B), W cerrado≈0, inversión cambia dr y trabajo pero no F en mismo punto.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
