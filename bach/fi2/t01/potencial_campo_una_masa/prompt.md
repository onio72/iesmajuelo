# Prompt de reconstrucción — Relación entre potencial y campo gravitatorio

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Mapa 2D y relieve 3D sincronizados (Three.js 0.170.0 y OrbitControls) de 1–4 masas, G=6,67430·10⁻¹¹, unidad de masa 10²⁴ kg y distancia 10⁶ m, regularización r≥4 px. V=−ΣGM/r, g=ΣGM(r_i−A)/r³. Dibuja flecha de campo 2D y vector tangente al descenso local del relieve 3D; arrastre de masas y A, añadir/eliminar, reiniciar A, contraste y profundidad visual 20–100. Lee potencial y campo numéricos y distingue escala comprimida. Verifica simetría y campo nulo en punto medio de dos masas iguales.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
