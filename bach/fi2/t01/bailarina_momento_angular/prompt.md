# Prompt de reconstrucción — La bailarina y la conservación del momento angular

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Bailarina esquemática en perspectiva, I=2+2·3r² kg·m², r entre 0,20 y 0,90 m según apertura 0–100%, ω₀ −3…3 rad/s paso 0,25 inicial 1,5 definida con brazos extendidos. L=I_extω₀ constante, ω=L/I, E=½Iω², T=2π/|ω| (sin giro, no período finito). Pausar/reiniciar. Explica trabajo muscular y que E no se conserva al cambiar I. Verifica L constante y ω aumenta en módulo al recoger brazos.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
