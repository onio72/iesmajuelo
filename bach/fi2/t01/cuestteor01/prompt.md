# Prompt de reconstrucción — Tema 1: Interacción gravitatoria. Control de variables (I)

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Generador de cuatro temas: F=GMm/r², g=GM/r², Ep=−GMm/r, V=−GM/r. Para Q=C∏x_i^{p_i}, el cociente Q₂/Q₁=∏factor_i^{p_i}; cancela constantes y compara magnitudes negativas mediante su cociente positivo sin confundir aumento algebraico con módulo. Sortea cambios independientes con factores 2,3,4,1/2,1/3,1/4; al menos un cambio. Formula comparación estado inicial azul y final rojo, opciones numéricas sin duplicados, simplifica fracciones con MathJax, feedback y puntuación, siguiente objetivo y calculadora. Comprueba invariancia cuando factores se compensan.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
