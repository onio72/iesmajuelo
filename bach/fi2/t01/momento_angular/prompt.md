# Prompt de reconstrucción — Momento angular de una partícula

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Canvas con círculo en perspectiva en plano XY, partícula, eje z y vectores r, v, L. I=mr², Lz=Iω, rapidez r|ω|. m 0,5–10 kg paso 0,5 inicial 2; r 0,5–4 m paso 0,1 inicial 2; ω −4…4 rad/s paso 0,1 inicial 1,5. Pausar/reanudar, reiniciar, casilla r y v, lecturas con unidades, calculadora científica. Verifica inversión de L con ω, L=0 para ω=0 y dependencia cuadrática de r.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
