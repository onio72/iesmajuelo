# Prompt de reconstrucción — Trabajo, energía potencial y campo gravitatorio

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Cuestionario GRAVITA de 61 ítems con cuatro alternativas, una correcta, explicación razonada y etiqueta temática. Incluye trabajo/producto escalar, fuerzas conservativas, energía cinética, potencial y mecánica, campo y potencial gravitatorios, órbitas y escape. Baraja preguntas y opciones conservando índice correcto, permite elegir número y modalidad de corrección, persistencia local del intento, salir/reanudar, resultados, nuevo intento, practicar fallos y copiar resultado. Mantén explicación y distractores conceptualmente cercanos; evita ambigüedad física. Usa el banco de la versión actual incluido al final.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
