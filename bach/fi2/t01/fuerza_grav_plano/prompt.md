# Prompt de reconstrucción — Fuerza gravitatoria de m₁ sobre m₂

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Sortea A,B enteros entre −4 y 4 m separados al menos 2 m, m₁,m₂ de 2–9·10⁹ kg. G=6,67·10⁻¹¹. d=B−A, r=|d|, u=d/r, Fm=Gm₁m₂/r², F₂=−Fm u. Cuadrícula divisiones 1 m, flecha de fuerza oculta hasta corregir, ocho respuestas de componentes y magnitudes, acepta coma/punto y notación científica, pista, calculadora, solución razonada y nuevo ejercicio. Verifica signo atractivo.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
