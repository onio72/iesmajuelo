# Prompt de reconstrucción — Campo gravitatorio de una masa puntual

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Canvas con fuente central y vectores radiales atractivos en círculos de referencia, g=−GM r̂/r², G=6,67430·10⁻¹¹. Masa deslizable 1–20 (escala 10¹¹ kg), paso 0,5 inicial 5; círculos 4–10 inicial 6, separación 15–45° paso 15 inicial 30. Flechas con escala visual comprimida no lineal para legibilidad, valores numéricos físicos, circunferencias parcialmente visibles. Ocultar vectores/cuadrícula, reiniciar, resize. Aclara que círculos no son líneas de campo.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
