# Prompt de reconstrucción — Momento de una fuerza · Regla del sacacorchos

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Escena tridimensional proyectada con barra, origen, r, F y M=r×F; controles de fase 0–300 y selector sentido. Tres etapas: copia paralela r′ trasladada hasta punto de aplicación, giro de r′ hacia F, rotación y desplazamiento axial del sacacorchos siguiendo M. Cámara orbitable y etiquetas; usa modelo 3D integrado o uno propio, si reutilizas Corkscrew from Poly by Google de Sketchfab conserva atribución CC BY. Verifica inversión del desplazamiento axial al invertir el producto vectorial; no confundir r′ auxiliar con r físico.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
