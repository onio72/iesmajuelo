# Prompt de reconstrucción — Excentricidad y órbitas elípticas

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Construye dos pestañas con SVG de elipse, focos y semiejes. Semieje mayor a constante; c=ae, b=a√(1−e²), periapsis a(1−e), apoapsis a(1+e). Deslizador e=0–0,85 paso 0,01, reinicio e=0. Segunda pestaña con selector de astros del Sistema Solar y sus excentricidades, elipse a escala de forma (no tamaño orbital), foco ocupado y circunferencia discontinua de referencia. Muestra e y medidas geométricas. Verifica b=a y focos coincidentes cuando e=0; distingue forma de tamaño.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
