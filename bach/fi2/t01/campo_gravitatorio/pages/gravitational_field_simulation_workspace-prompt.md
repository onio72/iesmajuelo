# Prompt de reconstrucción — Calculadora de Campo Gravitatorio

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Calculadora de campo gravitatorio en XY de dos masas, G=6,67430·10⁻¹¹, unidades seleccionables de distancia y masa, coordenadas numéricas y cuadrícula interactiva. d_i=r_i−P, g_i=GM_i d_i/|d_i|³, suma vectorial, módulo y dirección. Panel matemático con vectores de posición y unitarios, contribuciones y total; formato científico, calculadora, limpiar/auto, contraer panel. Evita coincidencia singular. Usa KaTeX opcional para expresiones. Verifica cancelación de campos con fuentes iguales en punto medio y ausencia de masa testigo en g.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
