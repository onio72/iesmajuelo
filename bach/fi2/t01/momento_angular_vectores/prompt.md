# Prompt de reconstrucción — Momento angular de una partícula en el espacio

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Genera r y p alineados con ejes cartesianos, aproximadamente 30% paralelos/antiparalelos y resto perpendiculares. L=r×p calculado por determinante, p=mv. SVG o Canvas 3D proyectado, ejes, partícula y flecha p desde la partícula; rotación por arrastre y botones, restablecer vista. Radio sí/no, eje x/y/z, signo ±, comprobación y nuevo ejercicio; feedback y puntuación según respuestas. Verifica r×p=0 si colineales y regla mano derecha, p×r cambia signo.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
