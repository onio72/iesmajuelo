# Prompt de reconstrucción — Energía potencial gravitatoria de dos masas en el plano

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Sortea coordenadas enteras x −9…9, y −5…5 no coincidentes, masas 1–9·10⁹ kg, G=6,67·10⁻¹¹. d=B−A, r=√(dx²+dy²), Ep=−Gm₁m₂/r, cero en infinito. SVG de cuadrícula, cuatro campos en cualquier orden, coma/punto y notación científica, comprobación y retroalimentación, calculadora auxiliar y otro ejercicio. Verifica Ep escalar negativa y simetría al intercambiar masas.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
