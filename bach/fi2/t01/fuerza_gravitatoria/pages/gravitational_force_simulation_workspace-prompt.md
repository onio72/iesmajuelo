# Prompt de reconstrucción — Calculadora de Fuerzas Gravitatorias

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Calculadora interactiva de fuerzas gravitatorias en XY con dos masas creadoras y M₃ de prueba. Unidades de distancia y masa seleccionables, conversiones SI, G=6,67430·10⁻¹¹. Para cada fuente d=r_i−r₃, u=d/|d|, F_i=GM_i M₃ u/|d|²; suma por componentes, magnitud y ángulo. Cuadrícula interactiva con colocación/arrastre, campos de coordenadas y actualización, limpiar y auto, panel de cálculo paso a paso, calculadora. Evita singularidades en coincidencias y diferencia escala gráfica de valores físicos. Verifica duplicar M₃ duplica ambas fuerzas.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
