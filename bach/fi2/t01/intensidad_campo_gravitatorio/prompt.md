# Prompt de reconstrucción — Intensidad del campo gravitatorio

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Fuente M₁ central y m₂ móvil en polar; M₁ 1–20 kg inicial 8, m₂ 1–10 kg paso 0,5 inicial 1, r 1–9 m paso 0,1 inicial 5, θ 0–359° inicial 35. F=GM₁m₂/r², g=F/m₂=GM₁/r², vectores desde m₂ hacia M₁, escalas visuales no lineales y valores exactos, alternar vectores y reiniciar. Canvas y drag con límites. Verifica al duplicar m₂ F duplica, g constante; duplicar r divide por 4.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
