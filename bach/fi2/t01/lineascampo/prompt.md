# Prompt de reconstrucción — Laboratorio gravitatorio v1.0

Crea desde cero una aplicación didáctica en español para Física de 2.º de Bachillerato. Prompt reconstruido a partir de la versión vigente, no original.

## Modelo e interacción

Canvas interactivo de 1–4 masas positivas, masa 1–5·10²⁴ kg, escala 1 px=10⁶ m, G=6,67430·10⁻¹¹. Calcula g por suma vectorial y V=−ΣGM/r con regularización mínima 3 px. Traza líneas por integración de dirección local normalizada y semillas proporcionales a masa, flechas entrantes; curvas equipotenciales por contornos de V. Controles líneas, equipotenciales, flechas, rejilla, masas visibles, densidad 4–32 paso 2 inicial 16, intervalo 1–10·10⁶ J/kg inicial 2. Arrastre, añadir/eliminar/ajustar, sonda, reiniciar. Verifica ortogonalidad local y distingue discos simbólicos de tamaños reales.

## Requisitos

Entrega código HTML, CSS y JavaScript funcional, sin servidor, responsive, con controles accesibles, unidades SI y botón Info en flujo normal junto al título. Comprueba los casos indicados.
