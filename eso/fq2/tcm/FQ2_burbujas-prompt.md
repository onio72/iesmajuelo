# Prompt de reconstrucción — Teoría cinético-molecular · Burbujas

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Canvas de líquido y burbujas de gas, partículas y velocidades diferenciadas, movimiento aleatorio, rebotes, ruptura por clic/toque, liberación del gas. Romper todas y Nuevas burbujas. Cuestionario conceptual +1/−1, feedback. Modelo cualitativo, no escala real.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
