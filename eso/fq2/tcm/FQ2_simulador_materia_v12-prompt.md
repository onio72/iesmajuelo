# Prompt de reconstrucción — Modelo de partículas de un sólido

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Canvas de sólido con posiciones de equilibrio organizadas, composiciones puras y mezclas, mono/diatómicas, colores y contorno completo. Temperatura 0–100 K inicial 50, vibración con dirección y fase aleatorias, amplitud dependiente de temperatura. Cambiar composición reinicia. Modelo cualitativo sin transición de fase.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
