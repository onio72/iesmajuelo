# Prompt de reconstrucción — Simulación de gas

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Canvas mono/diatómico, nueve composiciones puras simples/compuestas y mezclas homogéneas/heterogéneas. Temperatura 0–300 K paso 5, inicial 0; velocidad dependiente de temperatura, rebotes, moléculas ligadas, color por especie. Selector reinicia. Modelo cualitativo: separación heterogénea esquemática, no gases miscibles separados espontáneamente.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
