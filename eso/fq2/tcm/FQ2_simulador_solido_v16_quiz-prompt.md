# Prompt de reconstrucción — Quiz de composición de sólidos

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Sólidos con vibraciones y nueve categorías: pura simple mono/diatómica, pura compuesta diatómica, tres mezclas homogéneas y tres heterogéneas. Colores y parejas, sorteo barajado, radios, comprobación, feedback, nota y nuevo sólido. No revelar respuesta antes de corregir.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
