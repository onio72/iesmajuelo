# Prompt de reconstrucción — Interpretación de fórmulas químicas

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Banco de símbolos individuales, moléculas simples H₂,O₂,O₃,P₄,S₈ y compuestas H₂O y otras. Coeficientes enteros y subíndices, preguntas condicionales, cuenta átomos por elemento y totales; coeficiente multiplica toda fórmula. Corrección por pasos y reinicio. HTML y script.js; no confundir símbolo metálico con estructura del sólido.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
