# Prompt de reconstrucción — Variables de un experimento

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Banco de situaciones reales, variables independiente/dependiente, magnitudes, unidades y vocabulario ES/EN. Columnas en orden aleatorio, selectores, validación, feedback y otro experimento. No confundir variable controlada con dependiente.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
