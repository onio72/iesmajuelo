# Prompt de reconstrucción — De tabla a gráfica

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Seis pares de datos en cinco tipos de situaciones. Selectores magnitudes/unidades, máximo y paso X/Y, papel cuadriculado adaptable, herramientas punto y lápiz, deshacer y borrar línea, evaluación de interpretación, escala y puntos. Otra tabla reinicia.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
