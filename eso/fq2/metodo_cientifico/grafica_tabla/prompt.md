# Prompt de reconstrucción — De gráfica a tabla

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Casos experimentales aleatorios con gráfica y tabla parcial. Seis selectores de magnitudes independiente/dependiente, fundamental/derivada y unidades; huecos numéricos, opciones barajadas, evita repetir caso, feedback y siguiente. Conserva evaluación de primer intento.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
