# Prompt de reconstrucción — Notación científica

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Cinco bloques: decimal→científica, inversa, notación correcta, comparar con 1, comparar cantidades. Exponentes positivos/negativos equilibrados, 1≤|a|<10, coma/punto, coeficiente y exponente separados, feedback y progreso, superar bloques para alcanzar 5. Boletín 1–100, tipos y niveles seleccionables, solucionario separado e impresión.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
