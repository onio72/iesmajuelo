Crear un boletín de ejercicios

Elige cuántos ejercicios quieres, su dificultad y si deseas incorporar las soluciones al final del mismo documento.

Tipos de ejercicios que incluir

Puedes elegir uno o varios tipos. «Práctica mixta» reúne las siete modalidades anteriores y no las duplica. La dificultad se aplica a los tipos seleccionados.

Se abrirá el boletín listo para imprimir o guardar como PDF.

Las soluciones, si las incluyes, aparecerán después de todos los ejercicios, en páginas separadas. Cada boletín se genera con ejercicios nuevos.

Funciona sin conexión a Internet. Los boletines y los solucionarios se abren para imprimir o guardar como PDF desde el navegador. Se aceptan coma y punto decimales; las unidades distinguen mayúsculas de minúsculas.
