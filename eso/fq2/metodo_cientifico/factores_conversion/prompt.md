# Prompt de reconstrucción — Laboratorio de factores

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Ocho modos: prefijos, potencias/equivalencias, factores simples, superficies, volúmenes, capacidad↔volumen, dobles y mixta. Genera cantidades y notación científica, potencias correctas, 1 L=1 dm³, unidades compuestas. Editor de fracciones, validación, pistas, +2 acierto y −1 primer fallo, referencia. Boletín 1–100, tipos y niveles seleccionables, soluciones opcionales al final, impresión local. Coma/punto.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
