# Prompt de reconstrucción — Densidad y peso

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Problemas aleatorios bilingües de d=m/V y P=mg, despejes, conversiones g/cm³↔kg/m³, cm³↔mL, dm³↔L. Selector fórmula, resultado con coma/punto y unidad, pistas, solución, puntuación. Boletín 1–100 ejercicios con tema, idioma, dificultad y solucionario separado, espacio Datos–Fórmula–Operaciones–Solución, impresión PDF.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
