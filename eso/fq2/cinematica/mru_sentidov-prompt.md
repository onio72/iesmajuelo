# Prompt de reconstrucción — Dirección y gráficas de MRU

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Dos MRU x₀ distintos 0–10 y velocidades de módulos distintos 1–9, primera negativa y segunda de signo sorteado. Tablas, selectores dirección, gráficas Chart.js barajadas y distractores, asociación y corrección /100. Pendiente negativa implica izquierda independientemente de x.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
