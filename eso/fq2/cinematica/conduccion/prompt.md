# Prompt de reconstrucción — Cinemática al volante

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Vista conductor, nueve casos recta/curva izquierda/derecha con rapidez constante/aceleración/frenado. a tangencial 0 o ±1,25 m/s², curvatura 0 o ±1/145 m⁻¹. Velocímetro, ambientador inclinado opuesto a aceleración, componente longitudinal amplificada, normal v²/R. Actividad de 9 casos, modo libre, selector, anterior/siguiente, pausa/repetición, preguntas, puntuación y pantalla completa. Distingue rapidez y dirección.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
