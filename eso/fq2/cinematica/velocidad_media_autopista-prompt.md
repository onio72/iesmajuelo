# Prompt de reconstrucción — Velocidad media en autopista

Crea una aplicación didáctica en español para Física y Química de 2.º ESO. Prompt reconstruido, no original.

## Modelo e interacción

Vista cenital de dos MRU hacia derecha, bases 420/500/560/600/680 km, duración 90/120/150 s. Reloj 10× por defecto, pausa, ±10 s, reinicio, cursor y zoom 1–2 sin alterar física. Campos mm:ss y km, respuesta km/h a una decimal, cuatro pistas, solución y otro caso. v=3600Δx/Δt para tiempo en s.

## Requisitos

Entrega HTML, CSS y JavaScript funcionales, diseño adaptable, controles accesibles, unidades claras y botón Info en flujo normal. Conserva evaluación y verifica el modelo.
