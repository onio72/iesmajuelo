# Prompt de reconstrucción — Abundancia isotópica

Crea desde cero una aplicación educativa en español para Física y Química de 3.º de ESO. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Banco de isótopos naturales con símbolo, número másico aproximado y abundancia, agrupa elementos con varios isótopos. Gráfico circular Chart.js con etiquetas porcentuales y leyenda interactiva. Seis preguntas sobre número de isótopos, protones/Z, isótopo más abundante, símbolo y abundancia; séptima masa media Σ(A_i·%_i/100), aproximación usando números másicos. +0,05 cada una de seis, errores −0,02, masa media +0,95 si error <0,05 u o +0,45 si <0,2 u; máximo 1,25 por elemento, global 0–10. SCORM y bloqueo de corrección. Verifica abundancias normalizadas y masa entre extremos.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades y etiquetas claras y botón Info integrado en flujo normal con instrucciones. Conserva los criterios de evaluación y comprueba los casos indicados.
