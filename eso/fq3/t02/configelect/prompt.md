# Prompt de reconstrucción — Configuración electrónica por capas

Crea desde cero una aplicación educativa en español para Física y Química de 3.º de ESO. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Modelo de Bohr interactivo con elemento sorteado del banco, núcleo y capas, controles +/− y clic, límite de electrones por capa según modelo, contador y limpiar orbitales; valida distribución de estado fundamental y electrones externos. No confundir ocupación por capas con orbitales ni regla 2,8,8 universal. Progreso, feedback, SCORM persistente, objetivo puntuación máxima y finalizar/salir. Usa configuración real del banco y conserva las excepciones.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades y etiquetas claras y botón Info integrado en flujo normal con instrucciones. Conserva los criterios de evaluación y comprueba los casos indicados.
