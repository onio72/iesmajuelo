# Prompt de reconstrucción — Trabajando con la tabla periódica II

Crea desde cero una aplicación educativa en español para Física y Química de 3.º de ESO. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Tabla periódica muda con resaltado de un elemento sorteado, cuatro respuestas Z, grupo 1–18, período 1–7 y tipo (metal/no metal/semimetal/gas noble). Banco de posiciones y clasificación, orden variado sin repeticiones innecesarias. +0,25 acierto, −0,25 error, objetivo 10, feedback por campo y otro ejercicio. Diseño que recalcula escala al cambiar ventana u orientación.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades y etiquetas claras y botón Info integrado en flujo normal con instrucciones. Conserva los criterios de evaluación y comprueba los casos indicados.
