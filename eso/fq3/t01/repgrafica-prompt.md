# Prompt de reconstrucción — Representación gráfica de datos

Crea desde cero una aplicación educativa en español para Física y Química de 3.º de ESO. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Genera tablas de cinco pares con magnitudes y unidades: posición/tiempo, velocidad/tiempo, aceleración/tiempo, masa/volumen, temperatura/tiempo, intensidad/tiempo, energía/tiempo o masa, con pequeñas variaciones simuladas. Canvas con escalas adaptadas, ejes etiquetados, coordenadas bajo cursor, clic/toque en orden, deshacer, unir opcional. Teclado flechas, espacio, Enter, Ctrl+Enter, Backspace. Valida x e y separadamente con tolerancia gráfica, ±0,2 por coordenada, límite 0–10, bloqueo por ejercicio, SCORM. Verifica datos de tabla y ejes coherentes.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades y etiquetas claras y botón Info integrado en flujo normal con instrucciones. Conserva los criterios de evaluación y comprueba los casos indicados.
