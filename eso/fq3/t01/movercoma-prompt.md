# Prompt de reconstrucción — Escala de unidades y coma decimal

Crea desde cero una aplicación educativa en español para Física y Química de 3.º de ESO. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Visualización posicional de escala de unidades y dígitos, coma inicialmente tras último dígito, flechas y teclado para desplazarla. Rellena celdas atravesadas vacías con cero. Conserva ceros de relleno mientras se avanza en mismo sentido y elimina uno a uno solo al cruzarlos de regreso; nunca elimina cero interno de número. Indicador de unidad actual, borrar todo y reiniciar. Verifica cambios de una potencia de diez por posición.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades y etiquetas claras y botón Info integrado en flujo normal con instrucciones. Conserva los criterios de evaluación y comprueba los casos indicados.
