# Prompt de reconstrucción — Cambio de unidades de volumen

Crea desde cero una aplicación educativa en español para Física y Química de 3.º de ESO. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Conversiones entre m³, dm³, cm³ y kL,hL,daL,L,dL,cL,mL, equivalencias 1 dm³=1 L, 1 m³=1000 L, 1 cm³=1 mL. Genera cantidades y pares variados. Editor de factores como fracciones con números y unidades; añadir/quitar, validar cada equivalencia, cancelación dimensional por recuento de potencias, producto y resultado numérico, feedback visual tachando unidades, nota acumulada 0–10, nuevo ejercicio, Enter y Ctrl+Enter. Verifica 1 m³=10⁶ cm³ y conversiones cruzadas.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades y etiquetas claras y botón Info integrado en flujo normal con instrucciones. Conserva los criterios de evaluación y comprueba los casos indicados.
