# Prompt de reconstrucción — Predice el tipo de enlace

Crea desde cero una aplicación educativa en español para Física y Química de 3.º de ESO. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Juego de pares aleatorios de metales, no metales y gases nobles; casos metal/no metal, dos no metales, dos metales, gas noble; baraja orden, muestra fichas y modelos. Dos preguntas de tendencia (perder, ganar/compartir, estable) y tipo de enlace; valida, revela explicación, puntuación progresiva con +0,5 por acierto, objetivo 10, siguiente pareja y reinicio, SCORM/Moodle. Clasificación escolar aproximada; no generalizar que todos los pares reaccionan.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades y etiquetas claras y botón Info integrado en flujo normal con instrucciones. Conserva los criterios de evaluación y comprueba los casos indicados.
