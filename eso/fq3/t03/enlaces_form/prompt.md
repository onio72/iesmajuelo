# Prompt de reconstrucción — ¿Cómo enlazan los átomos?

Crea desde cero una aplicación educativa en español para Física y Química de 3.º de ESO. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Laboratorio animado Canvas con tres modos. Iónico: Na,Li,Mg,Ca con Cl,F,O, ajusta proporciones por cargas, muestra transferencia de electrones y red de iones. Covalente: H₂,Cl₂,O₂ (doble),HCl,H₂O angular,CH₄ tetraédrico,PH₃ piramidal; representa pares compartidos y capas. Metálico: Na,Fe,Mg,Al, cationes ordenados y electrones deslocalizados móviles. Selector por modo, estado neutro/animando/enlazado, Formar enlace y reset, leyendas y descripción. Colores diferenciados, requestAnimationFrame, resize; modelo esquemático, no trayectorias electrónicas reales. Conserva número de electrones y neutralidad global.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades y etiquetas claras y botón Info integrado en flujo normal con instrucciones. Conserva los criterios de evaluación y comprueba los casos indicados.
