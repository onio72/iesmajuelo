# Prompt de reconstrucción — Tabla de valencias

Crea desde cero una aplicación educativa en español para Física y Química de 3.º de ESO. Prompt reconstruido a partir de la versión actual, no original.

## Modelo y comportamiento

Tabla periódica interactiva con casillas numéricas para las valencias del banco de elementos de la versión didáctica. Ubica cada elemento por grupo/período, muestra símbolo, permite completar cada casilla, compara enteros con valor esperado, marca verde/rojo y puntuación porcentual redondeada; reinicio limpia valores y estilos. Distingue valencias didácticas de estados de oxidación con signo; no inventes valores universales.

## Requisitos

Entrega HTML, CSS y JavaScript completos y funcionales, diseño adaptable, controles accesibles, unidades y etiquetas claras y botón Info integrado en flujo normal con instrucciones. Conserva los criterios de evaluación y comprueba los casos indicados.
