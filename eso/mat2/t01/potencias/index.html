Propiedades que practicaremos
aᵐ · aⁿ = aᵐ⁺ⁿaᵐ : aⁿ = aᵐ⁻ⁿaⁿ · bⁿ = (a · b)ⁿaⁿ : bⁿ = (a : b)ⁿ(aᵐ)ⁿ = aᵐ·ⁿ

En las divisiones, el divisor nunca puede ser cero. En esta aplicación se proponen exponentes finales no negativos. Ojo: (−3)² = 9, pero −3² = −9.
