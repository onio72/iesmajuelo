# BLOQUES DE MATERIAS SIMULTÁNEAS
# Una asignación por línea: curso, tramo, etiqueta[, abreviatura del grupo]
# Días: L lunes, M martes, X miércoles, J jueves, V viernes.
# L1 = lunes a primera hora; L4 = lunes a cuarta hora (el recreo no cuenta).
# Cursos: 3ºESO, 4ºESO, 1ºBACH, 2ºBACH.
# Sin cuarta columna se aplica a todos los grupos y modalidades del curso.
# La cuarta columna usa la abreviatura del horario: 4A, 4CBi, 4CDiv, etc.
# Una asignación específica tiene prioridad sobre la del curso completo.
# La misma etiqueta vincula las sesiones de un bloque dentro del mismo horario.
# También se admiten etiquetas como Grupo 1 o Grupo 2.
# EJEMPLOS: quita # y ajusta los datos a la distribución oficial antes de usarlos.

4ºESO, X1, B1
4ºESO, J2, B2

4ºESO, J6, B3
