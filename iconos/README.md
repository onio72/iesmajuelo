# Biblioteca de iconos del IES El Majuelo

Repositorio público de recursos gráficos para presentaciones, documentos y páginas educativas del centro.

- `AGENTS.md`: instrucciones para agentes como Codex.
- `ESTILO.md`: identidad visual y formato.
- `catalogo.json`: lista de iconos aprobados o en preparación.
- `imagenes/`: versiones definitivas (se creará al importar los archivos).
- `referencias/`: ejemplos visuales de estilo y fachada (se creará al importar referencias).
- `index.html`: catálogo consultable publicado mediante GitHub Pages.

Los archivos se incorporarán después de revisar la colección local y elegir los iconos aprobados. La generación automática mediante IA necesitará un servicio de generación configurado; no se incluye ninguna clave API.
